Overview

One observer principle, modern model interfaces

MDOB carries disturbance observation beyond explicit plant models to simulators, cost-query interfaces, and learned world models.

Abstract

Robotic controllers increasingly rely on analytical models, simulators, cost-query interfaces, and learned world models. Physical deployment can deviate from nominal assumptions, and additional disturbances may arise even when the model itself is accurate.

MDOB separates two observable channels: state-effect disturbances, where the feedback state differs from its prediction, and cost disturbances, where the same query state receives different costs as the perceived environment changes. These estimates compensate future state rollouts and cost evaluation online without plant inversion or model retraining.

Core principle

Observe mismatch at the interface the controller already exposes, then carry that information into the next rollout.

Two channels

What changed: the realized state or its evaluation?

The distinction keeps physical motion mismatch separate from environmental changes that appear through task costs.

    Recover state-effect and local cost disturbances through sampled forward evaluations.

  3. 3
    Compensate

    Correct subsequent state propagation and the costs used to score candidate rollouts.

Cost transport

From fixed queries to a horizon-aware cost

Local query matches estimate how the observed cost pattern moved. Interpolation makes that estimate available at arbitrary rollout states, allowing the controller to evaluate where the high-cost region is expected to move.
